thefeed admin: problems first, server always in view

The Board is a status list: each feature shows its state, one fact and 60 days of uptime, with problems on top. Open one for its status page: what's wrong and what it affects, the numbers right now, 60 days of uptime, what it depends on, past incidents and its log. CPU, RAM, disk and network out stay pinned above the list. Control runs the server: stop answering, restart, stop and start, update and roll back, reboot or shut down the machine, add, rename, reorder and remove Telegram channels, X accounts and Nitter instances, and every setting the server has. Everything here is clickable and runs on sample data.

Design Read: a mobile-first admin console for one self-hosting operator, in thefeed's own colors and list style. Dials: ENERGY 1, RHYTHM 2, MOTION 2.

Why it looks like this

Board
Built like a status page, not a chat list: name and state on one line, the one fact that matters under it, and 60 days of uptime bars, so a bad week shows at a glance. Problems come first, counted in the group heading.
Sign-in
One admin, kept in the panel's own database, like Portainer. First run asks for a setup code the installer printed, so a public server can't be claimed by whoever finds the page first. Five wrong passwords mean a 5-minute wait.
Pinned line
You asked to see CPU, RAM, disk and network out first, so they sit above the list and open the Server tab.
Feature page
A status page, not a conversation: status and impact first with the actions beside them, then the numbers, uptime, what it depends on, incidents and the log.
Control
Sections on one side, the open section on the other, like the Board. Each change says when it takes effect, because that's how the server reads it: public channels apply at once, everything else waits for a restart, and all waiting changes gather in one notice with Discard and Restart.
Power
Disruptive actions confirm in place and say what readers lose. Shutting the machine down asks you to type the domain, since the panel can't turn it back on.
Color
thefeed's own tokens: blue only for actions and the current tab, green, amber and red only for health.
Type
Vazirmatn, thefeed's UI font, which also covers Persian. Monospace appears only for real log lines.
Icons
The app's own set from icons.js, so the panel reads as part of thefeed.
Theme
Dark by default like the app, with a working light theme under Control, Appearance.
Motion
Only the slide when a thread opens and press feedback. Numbers update without animation and can be paused.
Spacing
12 to 16 px gutters as in the app; Board rows and sections are split by headings and hairlines, not stacks of cards.
Sample data throughout; addresses use example.com. Redesign for antislop audit 001 (anti-slop/audit-001-2026-11-03.md).
